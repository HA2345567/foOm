# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public GitHub issues.

Use [GitHub's private vulnerability reporting](https://github.com/HA2345567/foOm/security/advisories/new) for this repository. Include the affected version or commit, platform, steps to reproduce, and any potential impact. Avoid attaching real screen recordings or other private user data; use a synthetic project where possible.

The maintainers will acknowledge reports as soon as practical, investigate privately, and coordinate a fix and disclosure with the reporter. No response-time guarantee or supported-version window is currently established.

## Scope

This policy covers the foOom desktop app, website, build and release workflows, and project files. Third-party dependencies should be reported to their maintainers as well when the issue is upstream.
